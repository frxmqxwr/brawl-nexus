# NEXUS INSIGHTS — источники данных и RU/EN

## Источники
- **Supercell API:** аккаунт, кубки, бравлеры, уровни силы, доступные гаджеты и звёздные силы.
- **Боевой журнал Supercell:** последние матчи, доступные в момент обращения. Не содержит полной истории за всё время.
- **Локальная история NEXUS:** до 700 уникальных боёв и 150 наблюдений кубков для каждого тега в localStorage на конкретном устройстве. Обновляется при открытии профиля и опросе журнала на открытой странице.
- **Brawlify:** ссылка на профиль открывается отдельно. Бои из истории Brawlify, его платные материалы и собственный показатель качества не копируются.

## Показатели
- Винрейт считает только матчи с явными результатами Victory/Defeat.
- Для карты требуется минимум три боя с известным исходом.
- Союзники определяются только по достоверным составам `battle.teams`.
- Наблюдения кубков начинаются с первого посещения, история не восстанавливается задним числом.
- Сохранение только в текущем браузере, без облачной синхронизации. Удаление данных сайта в браузере удалит накопленную историю.

## Перевод интерфейса
Клиентская локализация `i18n.js`: RU ↔ EN, постоянный выбор через `bn_locale`, поддержка динамических DOM-элементов, атрибутов и русских названий карт. 236 двуязычных пар названий карт хранятся отдельно внутри словаря. Переводы UI-дописей подключены дополнительными словарями и применяются к созданному JavaScript интерфейсу. Названия игроков, игровые теги, названия команд, бренды и оригинальные новости не переводятся, чтобы сохранить исходные данные.

**Важное ограничение:** для полной истории на всех устройствах понадобится серверная база данных и фоновый мониторинг; нынешнее решение намеренно локальное. Для реальных данных профиль должен быть успешно подключён к Supercell API.
