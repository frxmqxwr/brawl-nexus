# BRAWL//NEXUS 1.3 — карта, ротация, айдентика

## Дизайн

- Новый оригинальный фирменный логотип и отдельная эмблема, вырезанные из изображения, созданного для проекта.
- Гостевой аватар в шапке и боковой панели — новый персонаж Nexus. При загрузке реального профиля изображение заменяется игровой аватаркой из API.
- Оригинальные изображения бравлеров, карт и логотипы киберспортивных команд **не генерировались**: берутся из CDN Brawlify / турнирного сайта Supercell.

## Карты на главной странице

- Новый блок **«Ротация карт / MAP INTEL»** с карточками карт и изображениями из каталога.
- При нажатии: большая настоящая картинка карты, режим, рекомендации для левой / центральной / правой линии и подходящие бойцы с реальными игровыми портретами.
- Настройка «Открытая / Смешанная / Много стен» пересчитывает качественные рекомендации. Тип карты задаёт пользователь — картографический анализ точных препятствий ещё не реализован.
- Кнопка открывает META LAB, сохраняя выбранные режим и карту.
- Система чётко отличает **текущую ротацию** от **предпросмотра карт каталога**. Без Supercell API не рисует вымышленные live-события.

## Новые серверные API

- `GET /api/events` → Supercell `/v1/events/rotation`, кэш ~60 секунд. Требует `BRAWL_API_TOKEN` и исходящий IP из белого списка Supercell (или прокси с фиксированным IP).
- `GET /api/map-stats?mapId=15000000` → опциональный внешний аналитический feed `MAP_STATS_FEED_URL`; кэш ~10 минут. При отсутствии feed возвращает пустую статистику, а не нарисованные проценты.
- Киберспортивный feed `/api/esports` по-прежнему отдельный, карты в ротации — игровые события, не чемпионаты.

## Как подключить статистику побед

Supercell API **не отдаёт суммарные win rates на каждой карте**. Для подлинных процентов нужен собственный сбор battlelogs или сторонний аналитический источник.

`MAP_STATS_FEED_URL=https://твой-источник.example/api/map-stats`

Сервер добавит `?mapId=NNNNNNNN`; ожидается JSON:

```json
{
  "stats": [
    { "brawlerId": 16000015, "name": "Piper", "winRate": 54.7, "sampleSize": 2410 }
  ]
}
```

**Этот JSON — пример формата, не реальные данные.** Нельзя называть проценты «живыми», если нет актуального сбора и достаточной выборки.

## Что скинуть из документации

Открой **Documentation → events**, раскрой метод **Get Event Rotation** (`GET /events/rotation`) и пришли скрин метода / структуры ответа без ключа. Для проверки живого API можно предоставить только обезличенный фрагмент JSON из response: `items`, `event`, `mode`, `map`, `startTime`, `endTime`. Токен, Bearer и пароли не отправляй.
