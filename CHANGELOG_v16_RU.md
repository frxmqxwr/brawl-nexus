# BRAWL//NEXUS v1.6 — Game Icons / REDLINE

## Изменено

- Вкладка Pro Academy удалена из меню, страниц, навигации, обработчиков и локального XP.
- Главная страница: баннер и панель личной статистики (значения показываются только при реальном профиле), карточки текущей ротации с оригинальными иконками режимов, миниатюрами карт, тактическими пиками.
- Новые блоки главной: твой клуб с переходом к участникам, тактические подсказки, киберспорт с оригинальными эмблемами команд, быстрые ссылки на другие разделы.
- Профиль: более заметные кубки, рейтинговые значки, полнофигурные PNG бойцов на пьедестале, иконка прайма при наличии поля `prestige`, `prestigeLevel` или `prestigeTier` в API, более информативные строки истории игр.
- Реальные PNG загружаются из Brawlify CDN: brawlers/portraits, brawlers/model, brawlers/borders, game-modes/regular, prestiges/brawlers, club-badges/regular, ranked/regular. Иконки интерфейса, для которых у CDN нет однозначного идентификатора, остаются стилизованными SVG.
- Сохранены функции v1.5: закрепление основного тега, поиск игроков, клуб, live-ротация, драфт с жетоном, API Netlify и текущие переменные окружения.

## Честность данных

- Винрейты по карте появятся только после подключения статистического провайдера. Сайт не генерирует числовые проценты.
- Отображение прайма зависит от реального поля в ответе API. Без него значок не показывается.
- Подбор бойцов на карту — эвристика, а не доказанный игровой рейтинг.
- Внешние PNG должны быть доступны с устройства посетителя; до размещения проверьте, как CDN отображается в браузере.

## Публикация

1. Распакуйте `BRAWL_NEXUS_UPDATE_v16.zip`.
2. В существующем GitHub репозитории замените `index.html`, `styles.css`, `app.js`, добавьте этот changelog, затем commit в `main`.
3. Netlify автоматически выполнит `node build.js`, каталог публикации `dist`.
4. После Published обновите сайт с Ctrl+F5. Переменные `BRAWL_API_TOKEN` и `BRAWL_API_BASE_URL` не меняются.
