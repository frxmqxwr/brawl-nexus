# BRAWL//NEXUS — Brawl Stars Competitive Intelligence

Готовый фан-сайт с **пятью разделами**: Профиль, Киберспорт, Meta Lab, Pro Academy, Squad Hub. На главной есть общий обзор; справа внизу доступен Nexus Assistant.

## Быстрый запуск

**Windows:** распакуй архив и дважды нажми `START_WINDOWS.bat`. Потребуется Node.js 20 или новее. Открой http://localhost:8787.

**Linux/macOS:** запусти `./START_LINUX_MAC.sh` или `node server.js`, затем открой http://localhost:8787.

**Открыть просто `index.html`** тоже можно: работают дизайн, тактический драфт и Academy. Каталог загружается напрямую с BrawlAPI (если браузер позволяет). Для поиска профилей и живых сервисов нужен сервер.

## Что работает сразу

- Интерфейс с пятью разделами, адаптирован под телефон и ПК.
- **Оригинальные игровые PNG**, НЕ сгенерированные: бойцы, аватарки и ранги по прямым адресам CDN Brawlify (`cdn.brawlify.com`). PNG подгружаются через интернет; сам архив их **не содержит**. Это означает, что при блокировке CDN иконки не появятся.
- Каталог персонажей и карт через BrawlAPI, без токена. При потере доступа есть резервный каталог персонажей для драфта.
- Meta Lab: составы 3 на 3, баны, фильтры, поиск, выбор настоящей карты из BrawlAPI и объясняемые рекомендации по ролям, ручной оценке открытости карты и матчапам. Оценка 0–100 — **эвристика, не официальный процент побед**.
- Pro Academy: 7 обучающих сценариев, ответы, объяснения, локальные XP и уровни.
- Squad Hub: интерфейс тройки и локальное сохранение тегов; данные игроков поступают только при доступности источника.
- Киберспорт: ссылки на официальную трансляцию/сетку, официальные новости через сервер (при доступности загрузки), сценарный сравнительный калькулятор.
- Nexus Assistant: локальные правила по драфтам; **настоящий языковой ИИ доступен только после подключения API-ключа**.

## Подключить реальные профили и журнал боёв

1. Зайди на https://developer.brawlstars.com/ и создай ключ (требуется белый список публичного IP адреса сервера).
2. Скопируй `.env.example` в `.env` в той же папке.
3. Укажи `BRAWL_API_TOKEN=твой_ключ`.
4. Перезапусти сервер. Теперь вкладка «Мой профиль» ищет тег, показывает данные аккаунта и пытается получить историю матчей.

Если ключа Supercell нет, сервер попробует публичный endpoint BrawlTools. **Внимание:** BrawlTools объявил закрытие с 1 декабря 2026 года, поэтому для долгой работы нужен официальный API.

## Подключить Nexus AI

В `.env` задай `OPENAI_API_KEY` (отдельная подписка/API биллинг, не включён в ChatGPT). Ответы обрабатываются на сервере через OpenAI Responses API. Секрет не попадает в браузер. При отсутствии ключа помощник честно отвечает из локальных правил.

## Подключить живое киберспортивное расписание

Supercell Player API **не предоставляет** прямой публичный endpoint для BSC-матчей. В `.env` есть `ESPORTS_FEED_URL`: укажи URL своего или лицензированного JSON-провайдера. Формат ответа:

```json
{
  "matches": [
    {"teamA":"HMBLE","teamB":"NAVI","tournament":"BSC World Finals","when":"2026-11-21T13:00:00Z","live":false}
  ]
}
```

Это **пример схемы**, а не заявленное время реального матча. Когда feed не подключен, карточки показывают *демонстрационные сценарии*, явно помеченные как DEMO, а официальный сайт открывается по кнопке. «Прогноз» пока основан на вручную выставленных оценках формы и **не выдает их за реальную модель вероятности**.

## Честные ограничения

- Для рейтинговых значков используются пути `ranked/regular/{bronze|silver|gold|diamond|mythic|legendary|masters|pro}.png`. Нельзя гарантировать каждую новую версию 2026 года, пока CDN не разместит её по этим адресам. Сайт показывает PNG только из игровой коллекции и не дорисовывает вымышленные ранги.
- Официальный API не передаёт видеозапись или позиции героев в матче. Поэтому ИИ не может оценивать перемещения и тайминги на основе одного только Battle Log.
- У сайта нет доступа к твоему профилю или ключам, пока ты не настроишь источник.
- Сайт — самостоятельный фан-проект, не одобренный Supercell. Соблюдай правила Supercell Fan Content Policy.

## Отдельный файл для быстрой демонстрации

Рядом с архивом есть `BRAWL_NEXUS_PREVIEW.html` — весь CSS и JS в одном HTML, только игровые изображения и библиотеки загружаются по интернету. **Без сервера** поиск профиля, полноценный ИИ и свежий esports-feed не работают. Для полной версии используй ZIP и сервер.

## META LAB 1.2 — Жетон первого выбора
Жетон определяет очередность 1–2–2–1. Выбери, у кого жетон, занеси баны (или пропусти их) и отмечай бойцов в правильном порядке. Сторона меняется автоматически. Доступны отмена, неизвестный пик, мобильный интерфейс и локальное сохранение прогресса. Подробнее в README_NETLIFY_RU.md.
