# BRAWL//NEXUS 1.4 — REDLINE / публикация на Netlify

## Что уже подготовлено

- `netlify.toml` и `build.js` — собирают в `dist` только публичные HTML/CSS/JS, не публикуя `.env`, серверный код и секреты.
- `netlify/functions/api.mjs` — Netlify Function для `/api/status`, `/api/catalog`, `/api/maps`, `/api/icons`, `/api/events`, `/api/news`, `/api/esports`, `/api/player/TAG`, `/api/player/TAG/log`, `/api/ai`.
- Все API-запросы с секретами идут через серверную функцию, не из браузера.
- В Meta Lab есть Live Draft (ручной ввод бойцов и моментальный пересчёт контрпиков). В esports-feed обновления опрашиваются каждые 45 секунд, **если вкладка открыта**, без ложных обещаний о чтении матча из самой игры.

## 1. Разместить сайт

**Вариант A — GitHub (рекомендуется)**

1. Создай пустой репозиторий GitHub. Залей в корень содержимое папки `BRAWL_NEXUS` (не добавляй `.env`, токены и секреты).
2. В Netlify открой **Add new project → Import an existing project → GitHub** и выбери репозиторий.
3. **Base directory:** пусто (если файлы лежат в корне репозитория); **Build command:** `node build.js`; **Publish directory:** `dist`; **Functions directory:** `netlify/functions` — значения уже есть в `netlify.toml`.
4. Опубликуй проект. Готовый публичный адрес будет вида `https://имя.netlify.app`.
5. Проверь `https://имя.netlify.app/api/status`. Ожидается JSON c `netlify:true`.

**Вариант B — Netlify CLI**

1. Установи Node.js 20+ и выполни `npm install -g netlify-cli`.
2. Открой терминал в папке проекта и выполни `netlify login`, затем `netlify init`.
3. Запускай локально `netlify dev` для тестов функций и `netlify deploy --prod --build` для публикации. Обычное перетаскивание HTML-файла на Netlify Drop не заменяет сборку serverless-функций; выбирай импорт Git или CLI для полноценного сайта.

## 2. Переменные окружения

Netlify → **Site configuration / Project configuration → Environment variables**. **Не** сохраняй токены в `app.js`, HTML, `netlify.toml` или открытом репозитории.

| Переменная | Для чего | Обязательна |
|---|---|---|
| `BRAWL_API_TOKEN` | Official Brawl Stars profile и battlelog | Для профилей |
| `BRAWL_API_BASE_URL` | HTTPS URL своего API-прокси с разрешённым исходящим IP, заканчивающийся на `/v1` | Если нужен фиксированный IP и нет Private Connectivity |
| `OPENAI_API_KEY` | Генеративный Nexus AI | Для ИИ |
| `OPENAI_MODEL` | Модель, по умолчанию `gpt-5-mini` | Нет |
| `NEXUS_AI_ACCESS_CODE` | Секретный код пользователя для ограничения публичных запросов к платному ИИ | Настоятельно рекомендован |
| `ESPORTS_FEED_URL` | HTTPS API с действительным расписанием и live-флагами | Для реальных матчей на странице |

Вводи `NEXUS_AI_ACCESS_CODE` **только** в Netlify environment variables, затем в разделе **Подключения** на сайте вводи тот же код. Браузер хранит его в пределах сессии, не в исходниках. Это простая защита доступа, **не** замена полноценной аутентификации и серверных лимитов запросов для большого публичного сайта.

## 3. Почему Supercell может отвечать 403, даже с корректным ключом

Официальный Brawl Stars API привязывает ключ к разрешённым IP. **Обычная Netlify Function может менять исходящий IP**, поэтому постоянный доступ к профилям не гарантирован. Способы:

1. **Доступ к Netlify Private Connectivity**, предоставляющий документированный набор статических исходящих IP, если доступен твоему аккаунту. Добавь предоставленные IP в список разрешённых в Supercell developer portal.
2. **Отдельный HTTPS-сервер/прокси с фиксированным исходящим IP**. Добавь его IP в Supercell developer portal, настрой защищённый прокси к `api.brawlstars.com/v1` и укажи `BRAWL_API_BASE_URL=https://твой-прокси/v1`. Прокси должен сам аутентифицировать запросы и не быть общедоступным открытым прокси.

**Не нужно и нельзя присылать API-токен в чат.** Его безопасно вводить в Netlify environment variables.

## 4. Реальные киберспортивные данные

Официальный Player API **не предоставляет** публичный поток драфта, результаты BSC и live-пики. Сейчас, без внешнего feed, карточки матчей — явно помеченные примеры для анализа. Если добавишь внешний источник `ESPORTS_FEED_URL`, требуется JSON:

```json
{
  "matches": [
    {
      "teamA": "HMBLE",
      "teamB": "NAVI",
      "tournament": "Название турнира",
      "when": "2026-11-21T14:00:00Z",
      "live": false
    }
  ]
}
```

**Это пример формата, а не реальное расписание или прогноз матча.** При открытой вкладке киберспорта данные обновляются опросом примерно раз в 45 секунд (серверный кеш до 35 секунд). Информация об обновлении не должна восприниматься как гарантированная трансляция каждой карты/пика.

## 5. Live Draft — жетон первого выбора

Открой **Meta Lab → ЗАПУСТИТЬ LIVE DRAFT**.

1. Выбери **«Жетон у нас»** или **«Жетон у врагов»**. Сторону больше не нужно вручную менять при каждом пике.
2. Отметь до шести банов. Нажми «Закончить баны» для раннего перехода или дождись шестого бана.
3. Пики автоматически следуют порядку **1–2–2–1**: команда с жетоном берёт ходы **1, 4, 5**, а другая — **2, 3, 6**.
4. Нажми на портрет бойца или набери имя в поиске и нажми Enter. Текущий пик автоматически назначается нужной команде.
5. При пропущенном пике нажми «Пропустить пик»: появится неизвестный боец `?`, а ход перейдёт к следующему. Кнопка «Назад» отменяет последний выбор. Нажатие `×` в слоте откатывает последовательность до данного выбора.
6. Подсказки «NEXUS RECOMMENDS» пересчитываются мгновенно; добавить рекомендуемого бойца можно только **во время хода своей команды**.

Прогресс драфта (без кода API) сохраняется локально в браузере и может быть восстановлен после обновления страницы.

**Горячие клавиши:** `/` — поиск, `Enter` — первый подходящий боец, `Ctrl+Z` — отмена выбора (когда фокус не в поле), `Escape` — выход из Live Draft. Избранное ★ остаётся.

**Важное ограничение:** сайт не считывает пики с экрана Brawl Stars. Это помощник второго экрана с быстрым ручным вводом. Порядок 1–2–2–1 относится к последовательному Ranked-драфту; для режимов с одновременным выбором используют другие правила.

## 6. Источники оригинальных изображений

- Портреты, аватары, ранги: `https://cdn.brawlify.com`.
- Логотипы команд: `https://event.supercell.com/brawlstars/assets/team-logos/` (официальные PNG).
- Favicon, фирменный логотип Nexus и гостевая аватарка — собственные чёрно-красные иллюстрации проекта в папке `assets`. Оригинальные изображения игры используются отдельно.

Игровые изображения подтягиваются из этих сайтов, поэтому интернет нужен. Использование бренда — в рамках правил Supercell Fan Content Policy; проект неофициальный.

## 7. Подключение текущих рангов, клуба и автохарактера карты

Профиль теперь использует `club.name`, `club.tag`, `trophies`, `highestTrophies`, `rankedRankName`, `rankedElo`, `highestAllTimeRankedRankName`, `highestAllTimeRankedElo` из Player API. Сайт всегда оставляет пустые поля пустыми.

Тип карты определяется автоматически. Сначала проверяется справочник названий, а для неизвестных миниатюр используется предварительный анализ изображения в браузере, если есть CORS-доступ. **Это не точное определение положения стен или кустов.** Ротация и win rate поступают из разных источников.

## 8. Что прислать для следующего подключения

- Ссылку на раздел **Documentation** в `developer.brawlstars.com` либо скрин **только перечня методов API и требований** — без ключей, bearer-токенов, паролей и личных данных.
- Публичный тег Brawl Stars, если нужно протестировать конкретный профиль.
- Решение: размещение только на Netlify или Netlify + фиксированный сервер/прокси, если нужны гарантированно доступные профили.
- Если есть отдельный feed киберспорта — ссылку на **документацию** и формат событий, не приватный токен.

## 8. Обновление 1.3: ротация и статистика карт

См. `CHANGELOG_v13_RU.md`. Главная страница показывает карты с картинками и открывает разбор по нажатию.

**Настоящая ротация**: серверный `GET /api/events` обращается к `https://api.brawlstars.com/v1/events/rotation`, используя `BRAWL_API_TOKEN`; на Netlify остаётся требование к разрешённому исходящему IP. Без действующего токена или прокси сайт показывает **не LIVE**, а карты из каталога BrawlAPI с яркой пометкой.

**Win rate**: требуется дополнительный HTTPS провайдер с доказуемыми данными и числом матчей. Добавь переменную `MAP_STATS_FEED_URL` в Netlify, а его ответ должен содержать `stats:[{brawlerId,name,winRate,sampleSize}]` (см. changelog). Из официального events win rate не получить.

**Брендинг**: четыре WebP в папке `assets/` созданы из оригинального дизайна для BRAWL//NEXUS. Команда `node build.js` копирует их в `dist/assets/` для публикации. Гостевая аватарка автоматически заменяется иконкой игрока после загрузки настоящего профиля.
