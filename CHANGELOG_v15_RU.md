# BRAWL//NEXUS v1.5 — Player & Club Intelligence

## Исправления и новые возможности

- Исправлены URL значков рангов Brawlify: используются файлы с правильным регистром (`/ranked/regular/Mythic.png`, `/ranked/regular/Legendary.png` и т.д.). Если PNG отсутствует, выводится буквенное обозначение, а не сломанная картинка.
- Значок клуба загружается по `badgeId`, который возвращает официальный Supercell API, через `/club-badges/regular/{id}.png` или готовый `imageUrl` BrawlAPI.
- Профиль закрепляется в браузере (`bn_my_tag`), автоматически запрашивается при повторном входе. Другие игроки просматриваются во вкладке **Поиск игроков** без замены «Моего профиля».
- Отдельная вкладка **Мой клуб**: название, эмблема, кубки клуба, тип, требование по кубкам, состав, роли. Нажатие на участника открывает его статистику.
- Новый API-маршрут: `GET /api/club/%23TAG` и `GET /api/club/%23TAG/members`, на Node и Netlify Functions. Ключ только на сервере.
- Новая вкладка поиска с текущими и максимальными кубками, рейтингом, лучшими бойцами и последними матчами другого игрока.
- Лучшие бойцы в «Моём профиле» оформлены пьедесталом ТОП-3; используются **полнофигурные PNG-модели Brawlify**, а при отсутствии модели — игровая PNG-иконка, не арт.
- Режимы в боевом журнале и в ротации теперь подписаны по-русски; иконки режимов получаются из каталога BrawlAPI (`/api/gamemodes`).
- Приведены к единым размерам и выравниванию игровые аватары в шапке, на панели и в профиле.
- Исправлено наложение «фазы банов» на заголовок и фильтры; удалено `position:sticky` для проблемного блока.
- Убраны из главного интерфейса технические подписи типа `BRAWLAPI ONLINE` и `ДАННЫЕ SUPERCELL API`.
- Проверены страницы на ширине 360, 390 и 768 px, переход из клуба в игрока и работа двух новых маршрутов API на фикстурах.

## Ограничения

- Проверка PNG по реальной сети зависит от доступности CDN Brawlify; в офлайн Chromium изображения из внешнего CDN не загружаются. На сайте есть fallback для рангов, аватаров и PNG-моделей.
- Постоянный логин через Supercell ID **не реализован**. Закрепление собственного профиля — это сохранение публичного тега в localStorage текущего браузера, а не авторизация от имени владельца.
- Supercell API не предоставляет подробных координат/реплеев боя. WIN RATE по всем игрокам и картам требует отдельного статистического сервиса; не выдумывается.
- Если ваш клуб не предоставляет данные или сервер временно недоступен, интерфейс показывает ошибку, а не поддельные показатели.
