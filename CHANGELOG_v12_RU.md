# BRAWL//NEXUS v1.2 — изменения 21 ноября 2026

- Автоматический порядок пиков 1–2–2–1 по жетону первого выбора (у нас / у соперника).
- Баны — отдельная фаза с возможностью пропустить и досрочно закончить; шесть банов переводят к пикам.
- Автоматически назначаемые нашей команде / соперникам пики. Больше нет ручного переключения команды.
- Прогресс выбора: таймлайн шести ходов, цветные индикаторы, счётчики, подсказки.
- Отмена и откат к конкретному пику; пропуск неувиденного пика с знаком вопроса.
- Контрпики и индексы рекомендаций обновляются после каждого действия (локальная эвристика, не ML-винрейт).
- Прогресс драфта сохраняется в localStorage для восстановления после перезагрузки.
- Мобильная версия: 360, 390, 768 px; на этих размерах исправлена горизонтальная прокрутка на всех вкладках.
- Сохранена Netlify Functions конфигурация, официальный CDN изображений, эмблемы команд.

Примечание: автоматического считывания пиков Brawl Stars через Supercell API нет. Live здесь означает мгновенный пересчёт после ручного ввода.
