# BRAWL//NEXUS v1.4 — REDLINE EDITION

Дата: 21 ноября 2026 года.

## Реализовано

- Полностью заменены сине-бирюзовые цвета на тёмный графит, чёрный и красные акценты. Изменены фоны, навигация, карточки, шапка, кнопки, таблицы, карта и драфт.
- Использованы **новые оригинальные ассеты проекта**: созданный для сайта чёрно-красный логотип и стилизованный кибер-оператор вместо гостевого аватара. Они оптимизированы отдельно для узкой боковой панели и маленького слота профиля. Новый favicon создан из собственной эмблемы Nexus.
- При успешной загрузке аккаунта гостевой аватар заменяется на настоящий `player.icon.id` из BrawlAPI/оригинального игрового CDN. При ошибке загрузки возвращается локальная заглушка.
- По игровому тегу профиль показывает клуб: `club.name` и `club.tag`, а также текущие `trophies` и рекордные `highestTrophies`.
- Рейтинг показывает текущее значение `rankedRankName` + `rankedElo` и исторический максимум `highestAllTimeRankedRankName` + `highestAllTimeRankedElo` — если эти поля присутствуют в ответе официального Player API. Пустые поля не заменяются фиктивными.
- На главной и в META LAB удалён ручной выбор типа карты. По известным названиям тип берётся из локального тактического справочника; по другим картам сайт пытается оценить сложность миниатюры через Canvas (если CDN разрешает доступ к пикселям). Метод отмечен на экране, и результат такой оценки не выдаётся за подтверждённую разметку стен/кустов.
- Рекомендации по трём линиям автоматически учитывают новый тип выбранной карты. Переход с карты в Live Draft переносит саму карту и её классификацию.
- Отзывчивые блоки рангов и профиля для мобильных экранов. Проверка на 390 px — нет горизонтального скролла.

## Подключения, которые требуют твоих собственных ключей

Настрой `BRAWL_API_TOKEN` в серверных переменных. Официальный Player API и `/v1/events/rotation` **не могут работать без действующего серверного токена и IP, разрешённого Supercell**. Netlify Functions по умолчанию не гарантируют фиксированный исходящий адрес, поэтому при стандартном Netlify потребуется внешний прокси с фиксированным IP либо подходящая услуга Netlify.

Значки лиг, портреты бойцов, изображения карт и реальные игровые аватарки подгружаются из Brawlify CDN. Это оригинальные игровые ресурсы, не изображения, сгенерированные для сайта. Авторские логотип и гостевой аватар Nexus — исключение: это собственные сгенерированные иллюстрации проекта.

API ротации сообщает события и их время, но **не** геометрию карт и не статистику win rate. Проценты побед появляются только после подключения реального `MAP_STATS_FEED_URL`. Нельзя использовать учебные эвристики как измеренную игровую статистику.

## Проверки

- `node --check app.js`, `node --check server.js`, проверка скрипта Netlify Function.
- Модульные проверки автоматического определения характера карт, модели текущего/лучшего ранга, отображения клуба и статуса карты в драфте.
- Рендер в Chromium с тестовыми JSON-профилем и ротацией. Проверены оба типа карты и ширина мобильного окна 390px.
- Тестовые ответы не записаны в публичный сайт — они использовались только для локального прогона.

## Запуск

Локально: `node server.js` (Node 20+), затем `http://localhost:8787`.
Netlify: создай репозиторий и импортируй его в Netlify; `netlify.toml` вызывает `node build.js`, опубликованная директория `dist`, функция `netlify/functions/api.mjs`.

Ключи никогда не вставлять в HTML / `app.js`, не передавать в чат и не хранить в публичном репозитории.
